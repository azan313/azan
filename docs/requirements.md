# معلومات لازمة لاستكمال النظام
هذه القرارات لا تمنع تشغيل هيكل البداية، لكنها تمنع اعتماد نظام إنتاجي:
1. هل المطلوب ويب متعدد المستخدمين أم برنامج Windows يعمل دون إنترنت؟ وأين ستتم الاستضافة؟
2. دولة التشغيل والعملة والسنة المالية والضريبة ومتطلبات الفوترة والتكاملات المطلوبة.
3. الفروع والشركات وعدد المستخدمين ومصفوفة صلاحيات العرض والإضافة والتعديل والاعتماد والحذف.
4. دورة النقل: طلب، عرض سعر، عقد، أمر تحميل، رحلة، إثبات تسليم؛ أنواع تسعير الرحلة أو الطن أو المسافة.
5. المركبات المملوكة والمؤجرة ومقاولو النقل؛ مصروفات الوقود والصيانة وعهد وتسويات السائقين.
6. دليل الحسابات والأرصدة الافتتاحية والعملاء والموردون والبنوك والخزن وآلية الاعتماد والترحيل.
7. عينات من مستندات الرحلات والفواتير والسندات والتقارير وملفات الاستيراد بعد إزالة البيانات الحساسة.
8. سياسة النسخ الاحتياطي والاحتفاظ وسجل التدقيق، وهل يحتاج الحذف النهائي إلى موافقة المدير؟
9. الاسم والشعار وبيانات المنشأة، وخطة نقل نماذج بدل الانتقال القديمة.

## ترتيب التنفيذ
- اعتماد المتطلبات ونموذج البيانات.
- الخادم والمستخدمون والصلاحيات والنسخ الاحتياطي.
- النقل وربط المصروفات والمستندات.
- المحاسبة والاعتماد والتقارير ثم اختبار قبول المستخدم.
