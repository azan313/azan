# هيكل البداية
واجهة HTML وCSS وJavaScript بوحدات ES، دون اعتماديات خارجية أو عملية build. مناسبة لتثبيت سير العمل قبل اختيار الخادم.
- src/pages: لوحة التحكم، شاشة سجلات قابلة لإعادة الاستخدام، التقارير والإعدادات.
- src/components: بناء DOM آمن باستخدام textContent؛ لا يتم إدراج مدخلات المستخدم كـ HTML.
- src/services/storage.js: عزل التخزين المحلي ليُستبدل لاحقًا بـ API.
- src/services/accounting.js: مبالغ بوحدات العملة الصغرى الصحيحة.
- src/config.js: توصيف الوحدات والعملة.
- tests: اختبارات مبالغ وتقارير تشغيلية.

## نموذج العلاقات المقترح
العميل والمركبة والسائق لهم رحلات متعددة؛ لكل رحلة مصروفات متعددة.
المعرفات UUID. الواجهة تمنع حذف سجل مرتبط. الحقول الأولى فريدة داخل كل شاشة في هذه البداية.
يجب أن يفرض الخادم مستقبلًا المفاتيح الخارجية والتميّز والتحقق والصلاحيات أيضًا؛ قواعد المتصفح ليست حماية.

## المرحلة التالية
خادم API وقاعدة PostgreSQL مع migrations ونسخ احتياطي؛ تسجيل دخول وأدوار مدير ومحاسب ومشرف حركة؛ سجل تدقيق.
بعد اعتماد الدورة المحاسبية: دليل حسابات، قيد ورأس وبنود، فترات مالية، فواتير، سندات قبض وصرف وتخصيص دفعات.
قيمة الرحلة الحالية ليست فاتورة أو قيدًا. لا توجد ضرائب أو ترحيل أو مصادقة أو تزامن مستخدمين في النسخة الحالية.
يجب إجراء ترحيل بيانات صريح عند تغيير العملة أو بنية التخزين.
