# أذان — بداية نظام إدارة النقل والمحاسبة

هيكل بداية عملي بواجهة عربية RTL، قابل للتشغيل دون تثبيت حزم خارجية.
**الحالة: نموذج محلي لتطوير المتطلبات، وليس نظام محاسبة إنتاجيًا.**

## نتيجة فحص المستودع
كان README يحتوي على عنوان فقط. وُجدت أيضًا الملفات `table` و`table.html` و`بدل الانتقال .html`، وجميعها متطابقة لنموذج بدل انتقال، وتشير إلى CSS وصورة وملف Excel غير موجودة. تم الحفاظ عليها كما هي كمرجع تاريخي؛ نقطة البداية الجديدة هي index.html.

## التشغيل
المتطلبات: Python 3 للتقديم المحلي، وNode.js 22 أو أحدث لتشغيل الاختبارات.
```bash
git clone https://github.com/azan313/azan.git
cd azan
python3 -m http.server 8000 --bind 127.0.0.1
```
افتح http://localhost:8000. استخدم خادم HTTP؛ فتح index.html مباشرة قد يمنع تحميل وحدات JavaScript.
من فرع طلب الدمج: نفّذ `git switch starter/transport-accounting` بعد الاستنساخ.
الاختبارات: `npm test`، وفحص الصياغة: `npm run check`. لا يلزم npm install.

## الصفحات
| المسار | الوظيفة الحالية |
| --- | --- |
| #dashboard | أعداد المركبات والرحلات وإجمالي أجور النقل والمصروفات |
| #vehicles | إضافة وتعديل وحذف وبحث المركبات |
| #drivers | بيانات السائقين ورقم الإقامة |
| #customers | بيانات العملاء |
| #trips | ربط الرحلة بالعميل والمركبة والسائق وتسجيل الأجرة |
| #expenses | مصروفات مرتبطة برحلة |
| #reports | الفرق التشغيلي الإجمالي ولكل رحلة والطباعة |
| #settings | إعدادات البداية ومتطلبات الاستكمال |

ابدأ بالعملاء والمركبات والسائقين، ثم الرحلات ثم المصروفات. لا تُحذف السجلات المرتبطة.
تتوفر الطباعة من أعلى الصفحة. لا توجد بيانات تجريبية مسبقة أو مستخدمون أو كلمات مرور.

## تنظيم الملفات
- index.html: غلاف التطبيق والتنقل.
- src/pages/: الصفحات والسجلات.
- src/components/: عناصر الواجهة.
- src/services/: التخزين وحساب المبالغ.
- src/styles/: التنسيق المتجاوب والطباعة.
- src/config.js: الوحدات والعملة الافتراضية التجريبية SAR.
- tests/: اختبارات الحسابات.
- docs/: التصميم والمتطلبات المتبقية.
- .github/workflows/: التحقق الآلي.

## حدود النسخة
البيانات تُحفظ في localStorage للمتصفح والجهاز وعنوان الموقع الحالي فقط، وقد تضيع بمسح المتصفح. لا يوجد خادم أو حسابات دخول أو نسخ احتياطي أو مشاركة أو سجل تدقيق. لا تضع بيانات فعلية أو حساسة في هذه النسخة أو المستودع العام.
الأموال تُخزن بوحدات صحيحة (هللات) لتجنب جمع الكسور العشرية. الملخص يحسب أجور الرحلات ناقص المصروفات، ولا يمثل صافي الربح أو التحصيل أو ميزان مراجعة. لا توجد فواتير معتمدة أو ضريبة أو قيود مزدوجة.
العملة اختيار تجريبي، وتغييرها لا يحوّل المبالغ السابقة.
